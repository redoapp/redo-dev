## What the RyderShip integration does

Redo connects directly to RyderShip. After you sign in and authorize Redo,
Redo can:

- Create a consumer return in RyderShip when a return is approved in Redo and
  its shipping information is available
- Match the return to its original RyderShip order and products by order ID and
  SKU
- Send the return destination, carrier, tracking number, quantities, return
  reasons, and return actions to RyderShip
- Receive RyderShip return-status updates through webhooks
- Automatically process the return in Redo when RyderShip reports it completed

You do not need to request or enter API credentials. Redo supplies the
integration credentials, and RyderShip handles authorization through OAuth.

## Before you connect

Make sure the following are configured:

<AccordionGroup>
<Accordion title="RyderShip account" icon="circle-check">
You need an active RyderShip account and a login that can authorize the Redo
integration.
</Accordion>

<Accordion title="Products and orders in RyderShip" icon="box">
  The products and orders used for returns should already be imported into
  RyderShip through your normal Shopify or order-management connection. Redo
  uses the original RyderShip order and product records when creating a return.

  If you are testing in a RyderShip sandbox, you may need to import the test
  products and orders manually.
</Accordion>

<Accordion title="Shopify inventory location" icon="store">
  In Shopify, make sure inventory is stocked at the location associated with
  RyderShip. This keeps order routing and inventory behavior consistent between
  Shopify and your warehouse.
</Accordion>

<Accordion title="Return warehouse" icon="warehouse">
  Confirm that the RyderShip warehouse that receives returns is configured for
  your account. Redo uses the return location configured for the return, or the
  account's default RyderShip warehouse when applicable.
</Accordion>

<Accordion title="Redo access" icon="key">
You need access to manage integrations in the Redo merchant dashboard.
</Accordion>
</AccordionGroup>

## Connect RyderShip

<Steps>
<Step title="Open RyderShip in Redo">
In the Redo merchant dashboard, go to **Settings** > **Integrations**, open
**RyderShip**, and find the **Returns** connection.
</Step>

<Step title="Choose an environment">
Select **Production** for your live RyderShip account or **Sandbox** for a test
account.
</Step>

<Step title="Authorize Redo">
Click **Connect via RyderShip OAuth**, sign in to RyderShip, and approve access.
RyderShip then redirects you back to Redo. No API key or secret is required.
</Step>

<Step title="Confirm webhooks">
Open the RyderShip integration and confirm the webhook status is
**Subscribed**. Redo creates this subscription automatically. If it shows
**Not configured**, click **Subscribe** to retry.
</Step>

<Step title="Test a return">
Create and approve a test return with a shipping label. Confirm that it appears
in RyderShip with the expected order, products, warehouse, and tracking
information.
</Step>
</Steps>

## Return settings

The RyderShip integration includes these settings:

- **Create returns in Ryder** — Creates the corresponding RyderShip return when
  a return is approved in Redo. This is enabled by default.
- **Process returns from Ryder webhooks** — Processes the Redo return when
  RyderShip reports the return completed. This is enabled by default.
- **Force blind returns** — Creates every return without attaching the original
  RyderShip order. Redo includes identifying order and customer information in
  the return instead.
- **Blind returns fallback** — Uses a blind return only when Redo cannot find
  the original order in RyderShip.

Most merchants should leave the default settings enabled. Use blind returns
only when your RyderShip workflow does not reliably contain the original order.

## Update timing

Return creation happens as part of Redo's return approval flow once shipping
information is available. RyderShip status changes are sent to Redo by webhook,
so completed returns can be processed shortly after RyderShip sends the update.
Actual warehouse receiving time still depends on your RyderShip service level.
