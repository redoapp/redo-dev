# Redo Developer Documentation

Official documentation for the Redo returns and exchanges platform API.
See [Documentation](https://developer.getredo.com/).

## Development

Install the Mintlify CLI:

```bash
npm i -g mint
```

CD into the Mintlify docs folder 

```bash
cd redo/docs
```

Run the development server:

```bash
mint dev
```

View your local preview at `http://localhost:3000`.

Reference [Mintlify Development](redo/docs/development.mdx) for more details on the Mintlify CLI
